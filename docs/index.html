WireGuard for C++14

基于 WireGuard 白皮书，使用 C++14 跨平台重新实现的 VPN 项目 。

官方 WireGuard 的 C 实现依赖大量 Linux 内核方法，Go 实现又缺乏对 HarmonyOS 的直接支持。 因此我们依照白皮书，用可跨平台的 C++ 从零重新构建了整条协议栈， 让新兴的鸿蒙平台也能稳定、安全地接入 WireGuard 组网。
