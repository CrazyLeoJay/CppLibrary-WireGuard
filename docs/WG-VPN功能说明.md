# WG-VPN项目功能说明

## 定位背景

基于WireGuard协议进行实现的VPN项目。主要用于跨网路加密安全组网。



## 功能

- 主页启动后，可以通过右下角加号，通过三种方式导入配置。
- 导入配置后，在主页会有列表显示，每个item都有开关来开启或者关闭VPN
  - 导入配置支持导入原版WireGuardapk导出的zip文件。
- 每一行向左滑动，都可以删除当前配置。删除有两种方式，向左滑动，点击露出来的删除按钮，或者持续向左滑动，会有提示文字，直到显示松开删除会进行删除。
- 设置中，可以将所有配置导出到zip文件进行备份。
- 点击配置进入预览界面。预览界面也可以开启或者关闭VPN。
- 预览界面可以卡到具体配置、应用过滤、连接流量。
- 在预览界面，当配置是域名配置时：
  - 可以看到解析连接的ip地址
  - 可以手动点击解析测试来看当前网络环境解析ip
- 配置界面。新增和修改都是一个界面。
- 应用过滤功能
  - 支持黑白名单配置，但只能配置一个。配置包名。
  - 由于HarmonyOs不支持获取应用列表，所以我通过剪贴板、分享功能实现。仅限于在应用市场上架的app。
  - 复制获取：长按应用，点击分享，最下方有复制按钮，可以复制该应用在应用市场的连接。然后到配置界面（会有权限请求），会显从剪贴板获取，并且会有获取的样式。
  - 分享获取：长按应用，找到WG-VPN应用，点击应用，选择对应配置。会有操作界面，会显示要导入的配置和配置列表，选择要添加的配置。如果是未开启应用过滤的配置，还可以选择黑名单或者白名单方式。如果已经开启，则直接按照配置规则加入。
  - 手动输入：在配置界面，开启应用过滤，选择黑白名单，点击添加应用。不需要的配置可以点击右边的删除按钮删除选择行。最后保存配置后生效。
